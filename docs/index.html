Windows 11 in Docker.
One command.

Wormhole installs Windows 11 as a container on any Linux server, then gives you Remote Desktop and a desktop in your browser. Windows stays on disk - restarts never reset it.

curl -fsSL https://raw.githubusercontent.com/bhxuk/Wormhole/main/install.sh | sudo bash

Needs a Linux x86_64 server with KVM and the official Windows 11 ISO from Microsoft.

What you get

Guided installer

A few questions - ISO, location, ports, login - with a summary to confirm before anything starts.

Hands-off setup

Windows installs itself unattended. No setup screens, no Microsoft account.

Browser desktop

Open http://server:8006 and use Windows from any device.

Remote Desktop

Full RDP on a port you pick, plus a ready-made .rdp file.

Persistent

The same Windows boots every time - container, Docker and server reboots included.

Easy updates

wormhole update pulls the latest version and keeps your Windows disk.

Install

Takes a couple of minutes, then Windows installs itself in 10-30 minutes.

  1. Download the ISO from microsoft.com/software-download/windows11 - choose Download Windows 11 Disk Image (ISO) for x64 devices - and copy it to your server. Any file name containing windows11 or win11 is found automatically.
  2. Run the installer as root: curl -fsSL https://raw.githubusercontent.com/bhxuk/Wormhole/main/install.sh | sudo bash
  3. Confirm the ISO it found, and where to install (default /opt/wormhole).
  4. Pick resources and ports - CPU, RAM, disk, and easy free ports like 8006 / 8080 for the browser and 3389 / 3390 for RDP.
  5. Set the login - computer (RDP) name, username and password, or let it generate one.
  6. Confirm the summary and the files created. Wormhole starts and prints your browser URL, RDP address and login.

Requirements

ServerLinux, x86_64, hardware virtualisation (/dev/kvm). A VPS needs nested virtualisation.
Resources2+ CPU cores, 4+ GB RAM and 40+ GB disk for Windows (more is better).
SoftwareDocker with Compose - the installer can install it.
WindowsYour own official Windows 11 ISO and licence.

Connect

Browserhttp://<server-ip>:<web-port> - watch the install, then use the desktop.
RDP<server-ip>:<rdp-port> in Remote Desktop Connection, Microsoft Remote Desktop / Windows App or Remmina.
RDP file/opt/wormhole/<NAME>.rdp - copy to your PC and double-click.
DetailsRun wormhole info on the server at any time.

Manage

wormhole info        connection details (browser URL, RDP, login)
wormhole status      installing / ready / stopped
wormhole start       start Windows
wormhole stop        shut Windows down cleanly
wormhole restart     restart Windows (keeps everything)
wormhole logs        follow the container log
wormhole update      update Wormhole - your Windows disk is kept
wormhole edit        change ports / CPU / RAM
wormhole uninstall   remove (asks before deleting Windows)

FAQ

Does Wormhole include or activate Windows?

No. You download the official ISO from Microsoft. Setup uses Microsoft's generic key only to choose the edition - activate with your own licence in Settings → Activation.

Will a reboot reset Windows?

No. Windows lives in /opt/wormhole/storage. Container restarts, Docker restarts and server reboots all boot the same Windows. Only deleting that folder removes it.

Can I change CPU, RAM or disk size later?

Yes - run wormhole edit. The disk can grow (extend C: in Disk Management afterwards).

The installer says /dev/kvm is missing.

Turn on VT-x / AMD-V in the BIOS, or ask your hosting provider for nested virtualisation. Windows is unusably slow without it.

How long does the install take?

Usually 10-30 minutes depending on the server. Watch progress in the browser; RDP works once Windows reaches the desktop.
